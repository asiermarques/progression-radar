key: ai
name: AI Systems
description: Designs, builds and operates systems powered by machine learning and language models, from prompts and retrieval to agents, evaluations and serving
---

## Level 1

### Understands how language models work and fail

**Example behaviours:**

* Explains tokens, context windows, temperature and why a model can hallucinate
* Calls a model API from code with structured outputs, and handles timeouts, rate limits and errors

### Writes clear prompts and tests them

**Example behaviours:**

* Writes prompts with instructions, examples and output format, and keeps them under version control
* Checks a prompt against a handful of real cases before considering it done

## Level 2

### Builds features with retrieval and tool use

**Example behaviours:**

* Builds retrieval-augmented generation (RAG) with chunking, embeddings and a vector store
* Gives a model tools to call and validates their inputs and outputs
* Streams responses and designs the user experience around latency and uncertainty

### Measures quality with evaluations

**Example behaviours:**

* Builds an evaluation set from real cases and runs it on every change of prompt or model
* Tracks quality, latency and cost per request

## Level 3

### Designs agents that are reliable in production

**Example behaviours:**

* Designs agent loops with clear goals, limited tools, checkpoints and human approval where it matters
* Adds guardrails against prompt injection, data leaks and harmful outputs
* Debugs agents from their traces and fixes the root cause, not only the symptom

### Chooses the right model and technique for the problem

**Example behaviours:**

* Compares models on the team's own evaluations, not on public benchmarks alone
* Knows when prompting is enough and when fine-tuning, distillation or a classic model is the better choice

## Level 4

### Designs the AI architecture of a product or platform

**Example behaviours:**

* Designs shared components used by several teams, such as a model gateway (routing, quotas, logging and fallbacks between providers), an agent runtime, an evaluation service or a prompt registry
* Balances quality, latency and cost with caching, routing between models and batching
* Defines how AI features are monitored, rolled out and rolled back

### Leads the evaluation practice

**Example behaviours:**

* Introduces LLM-as-judge, human review and online metrics, and knows the limits of each one
* Teaches other teams to write evaluations before they write prompts

## Level 5

### Sets the AI strategy of the company

**Example behaviours:**

* Decides what to build, buy or fine-tune, and which model providers to depend on
* Anticipates changes in model capabilities and prepares the architecture for them
* Represents the company in the AI community through talks, papers or open source
